# Security policy

Report a suspected vulnerability privately using GitHub's private
vulnerability reporting, available from the Security and quality tab
of this repository once it is turned on for the repository.
Please do not open a public issue or pull request for a security
problem.

A way to make the service answer wrongly for a listed host, or to crash
it with a crafted request, counts as a security problem.

Supported versions: the newest image built from `main` and the code at the latest `v*` tag.
